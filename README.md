## About Me

I'm not a formally trained programmer.

I didn't study computer science, attend coding bootcamps, or take professional programming courses.

I'm simply curious about how things work, enthusiastic about technology, and willing to keep experimenting until a problem is solved.

Most of my projects started from problems I experienced myself. I use AI to help me understand unfamiliar concepts, explore possible solutions, review my work, and turn ideas into working tools.

> I don't build projects just to fill a portfolio.
> I build them because something bothered me enough to try fixing it.

## Featured Projects

### [DrawdownLab](https://github.com/alfanzaky/DrawdownLab)

A trading journal and portfolio analysis application built from my own needs as a trader.

`Laravel` `Vue.js` `Inertia.js` `MySQL` `Trading Analytics`

---

### [KA200DG Linux](https://github.com/alfanzaky/ka200dg-linux)

A Linux daemon created to make the KYO KA200DG CPU display work without its official Windows application.

The project communicates directly with the device through USB and displays real-time CPU temperature and usage data.

`Python` `PyUSB` `systemd` `Linux` `USB HID`

---

### [Ultimate Linux Tool Project Manager](https://github.com/alfanzaky/Ultimate-Linux-Tool-Project-Manager)

A terminal-based tool for navigating, managing, and diagnosing development projects on Linux.

`Bash` `FZF` `Git` `Linux Automation`
